# EssaStudio first render proof of concept

This is a fixed, trusted Remotion composition used to validate the first real MP4 render.
It is deliberately separate from user-supplied project code.

Run the GitHub Actions workflow **EssaStudio - First 1080p Video** manually from the private repository's Actions tab, selecting branch `essa74/patch-66314`.

The workflow renders a 7-second 1920x1080 H.264 MP4 and uploads it as a private Actions artifact for 7 days.

GitHub Actions usage is subject to the account's included minutes and storage quotas. This is not unlimited free rendering.
